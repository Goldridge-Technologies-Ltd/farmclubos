
# FARMCLUB OS Website Project Brief

## Project Objective

Rebuild the FARMCLUB OS public-facing website as a maintainable,
responsive and production-quality Next.js application.

The website must communicate FARMCLUB OS as the digital platform for:

- Agricultural entrepreneurship
- Learning and capacity building
- Enterprise development
- Innovation
- Market access
- Finance access
- Networks and ecosystem collaboration
- Impact intelligence

## Primary Audiences

- Aspiring agricultural entrepreneurs
- Existing agribusinesses
- Young people and women
- Innovators and researchers
- Educational institutions
- Development organisations
- Corporate partners
- Government institutions
- Financial institutions
- Investors

## Public Website Pages

- Home
- About
- Platform
- Hubs
- Knowledge Centre
- Investors
- Contact
- Privacy Policy
- Terms of Service

## Initial Product Scope

The first release is a public website, not the complete authenticated
FARMCLUB OS application.

The architecture must allow later additions including:

- Authentication
- User profiles
- Learning programmes
- Enterprise tools
- Innovation challenges
- Market connections
- Finance applications
- Institutional dashboards
- Impact reporting
- Administrative tools

## Deployment Direction

The initial release should be suitable for deployment on Vercel.

## Backend Direction

The first release should be static-first.

Forms should be structured so they can later connect to:

- Supabase
- PostgreSQL
- Transactional email
- Newsletter services
- Spam protection

Do not build the complete backend during the first frontend pass.
